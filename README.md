# AI Team Mate Vision

**AI Team Mate Vision** is an AI-powered virtual sports assistant built around augmented reality and smart-glasses use.

## Concept

The user can see a virtual personal trainer directly in their field of view. The assistant can:

- demonstrate exercises in real time;
- guide a workout step by step;
- count repetitions and manage rest intervals;
- display connected wearable data such as heart rate;
- provide technique and form guidance;
- support a customizable virtual coach;
- offer an additional smartphone AR mode for recognizing gym equipment and showing exercise instructions over the real environment.

## Business use

The concept is designed not only for individual users but also for:

- gyms;
- fitness clubs;
- sports centers;
- yoga and Pilates studios;
- training groups and sports sections.

A club could own a shared pool of smart glasses and provide them to customers during training.

## MVP

This repository contains the first browser-based MVP concept. It demonstrates:

- virtual coach UI;
- live workout metrics;
- repetition counting;
- rest timer;
- exercise selection;
- coaching tips;
- wearable-data simulation;
- smartphone AR concept.

## Run locally

No build step is required.

1. Download or clone the repository.
2. Open `index.html` in a browser.
